nf-core 커뮤니티 프로젝트에서 파이프라인을 찾고, 실행하고, 설정하는 방법을 빠르게 학습합니다. 최소한의 데모 파이프라인부터 시작하여 프로덕션 규모의 분석 파이프라인까지 단계적으로 확장합니다.
