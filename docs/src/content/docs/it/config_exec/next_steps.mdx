Congratulazioni per aver completato il corso di formazione Configure Execution! 🎉

## Il vostro percorso

Avete iniziato adattando l'esecuzione di una pipeline a diversi ambienti di calcolo: cambiando la tecnologia di packaging del software e selezionando una piattaforma di esecuzione.
Successivamente, avete imparato a controllare le allocazioni delle risorse e a riprovare automaticamente le attività che falliscono.
Infine, avete imparato come raggruppare la configurazione in profili, combinarli in fase di esecuzione e ispezionare la configurazione completamente risolta.

### Competenze acquisite

Attraverso questo corso pratico, avete imparato come:

- Passare da una tecnologia di packaging del software all'altra tra Docker e Conda
- Selezionare una piattaforma di esecuzione e capire cosa cambia dietro le quinte quando lo si fa
- Controllare le allocazioni delle risorse per processo e riprovare automaticamente le attività che falliscono
- Definire e combinare profili e ispezionare la configurazione risolta con `nextflow config`

Siete ora pronti a configurare le pipeline Nextflow per una serie di ambienti di calcolo con sicurezza.
