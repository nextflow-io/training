Estes são cursos que demonstram como aplicar os conceitos e componentes apresentados no curso para iniciantes [Hello Nextflow](../hello_nextflow/index.mdx) a casos de uso científicos específicos. Cada curso consiste em uma série de módulos de treinamento projetados para ajudar os alunos a desenvolver suas habilidades progressivamente.

:::note[Nextflow para Genômica]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Aprenda a desenvolver um pipeline para genômica em Nextflow.

</div>

Este é um curso para pesquisadores que desejam aprender como desenvolver seus próprios pipelines de genômica. O curso usa um caso de uso de chamada de variantes para demonstrar como desenvolver um pipeline de genômica simples, mas funcional.

<div class="starlight-aside starlight-aside--tip inline end">

Este é um curso para pesquisadores que desejam aprender como desenvolver seus próprios pipelines de RNAseq. O curso usa um caso de uso de processamento de RNAseq em bulk para demonstrar como desenvolver um pipeline de RNAseq simples, mas funcional.

<LinkButton href="rnaseq/index.mdx" variant="primary" icon="right-arrow">Iniciar o treinamento Nextflow para RNAseq</LinkButton>

:::note[Nextflow para Bioimagem]
