These are courses that demonstrate how to apply the concepts and components presented in the [Hello Nextflow](../hello_nextflow/index.mdx) beginner course to specific scientific use cases. Each course consists of a series of training modules that are designed to help learners build up their skills progressively.

:::note[Nextflow for Genomics]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Learn to develop a pipeline for genomics in Nextflow.

</div>

This is a course for researchers who wish to learn how to develop their own genomics pipelines. The course uses a variant calling use case to demonstrate how to develop a simple but functional genomics pipeline.

<LinkButton href="genomics/index.mdx" variant="primary" icon="right-arrow">Start the Nextflow for Genomics training</LinkButton>
:::

:::note[Nextflow for RNAseq]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Learn to develop a pipeline for RNAseq data processing in Nextflow.

</div>

This is a course for researchers who wish to learn how to develop their own RNAseq pipelines. The course uses a bulk RNAseq processing use case to demonstrate how to develop a simple but functional RNAseq pipeline.

<LinkButton href="rnaseq/index.mdx" variant="primary" icon="right-arrow">Start the Nextflow for RNAseq training</LinkButton>
:::

:::note[Nextflow for Bioimaging]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Learn to run pipelines for imaging data in Nextflow.

</div>

This is a course for researchers who wish to learn how to run and configure bioimaging pipelines. The course uses nf-core/molkart to demonstrate essential Nextflow usage patterns applicable to any pipeline.

<LinkButton href="imaging/index.mdx" variant="primary" icon="right-arrow">Start the Nextflow for Bioimaging training</LinkButton>
:::

Let us know what other domains and use cases you'd like to see covered here by posting in the [Training section](https://community.seqera.io/c/training/) of the community forum.
