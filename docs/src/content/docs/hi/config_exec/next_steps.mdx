Configure Execution प्रशिक्षण कोर्स पूरा करने पर बधाई! 🎉

## तुम्हारी यात्रा

तुमने एक पाइपलाइन की execution को अलग-अलग compute वातावरण के अनुसार अनुकूलित करने से शुरुआत की: सॉफ़्टवेयर पैकेजिंग तकनीक बदलना और execution प्लेटफ़ॉर्म चुनना।
इसके बाद, तुमने resource आवंटन को नियंत्रित करना और विफल होने वाले कार्यों को स्वचालित रूप से दोबारा चलाना सीखा।
अंत में, तुमने कॉन्फ़िगरेशन को profiles में बंडल करना, उन्हें runtime पर मिलाना, और पूरी तरह से resolved कॉन्फ़िगरेशन को inspect करना सीखा।

### अर्जित कौशल

इस व्यावहारिक कोर्स के माध्यम से, तुमने सीखा कि कैसे:

- Docker और Conda के बीच सॉफ़्टवेयर पैकेजिंग तकनीक बदलें
- Execution प्लेटफ़ॉर्म चुनें, और समझें कि ऐसा करने पर पर्दे के पीछे क्या बदलता है
- प्रति-प्रोसेस resource आवंटन को नियंत्रित करें, और विफल होने वाले कार्यों को स्वचालित रूप से दोबारा चलाएं
- Profiles को परिभाषित और मिलाएं, और `nextflow config` से resolved कॉन्फ़िगरेशन inspect करें

अब तुम आत्मविश्वास के साथ विभिन्न compute वातावरणों के लिए Nextflow पाइपलाइन कॉन्फ़िगर करने में सक्षम हो।
