## El vostre recorregut

Heu començat registrant-vos a Seqera Platform i explorant el Community Showcase, després heu llançat un pipeline de producció, `nf-core/rnaseq`, des de la interfície web i n'heu monitoritzat l'execució.
A continuació, heu autenticat el CLI `tw` i heu après a fer-ho tot des del terminal.
Finalment, heu registrat un nou pipeline, `nf-core/demo`, des de GitHub i l'heu llançat tant des de la interfície web com des del CLI.

### Què heu après

Ara sou capaços de llançar i monitoritzar pipelines de Nextflow a Seqera Platform, tant si preferiu la interfície web com la línia de comandes.

- Un compte gratuït de Seqera us proporciona un espai de treball personal i accés al Community Showcase.
- Els pipelines afegits a un espai de treball apareixen al Launchpad i es poden llançar amb uns quants clics.
- El CLI `tw` ofereix les mateixes funcionalitats que la interfície web, i és útil per a scripts i automatització.
- Qualsevol pipeline allotjat a GitHub amb un `main.nf` i un `nextflow.config` es pot registrar amb `tw pipelines add`.
- `tw launch` accepta paràmetres mitjançant perfils i `--params-file`, en lloc d'indicadors individuals.

### Habilitats adquirides

A través d'aquest curs pràctic, heu après a:

- Registrar-vos a Seqera Platform i explorar el Community Showcase
- Afegir un pipeline a un espai de treball i llançar una execució des de la interfície web
- Monitoritzar l'execució i inspeccionar els detalls i informes a nivell de tasca
- Autenticar i utilitzar el CLI `tw` per gestionar i llançar pipelines des del terminal
- Registrar un pipeline allotjat a GitHub i llançar-lo amb un fitxer de paràmetres

Ara esteu preparats per executar i monitoritzar els vostres propis pipelines a Seqera Platform, a escala.
