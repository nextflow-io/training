Aquests són cursos que demostren com aplicar els conceptes i components presentats al curs per a principiants [Hello Nextflow](../hello_nextflow/index.mdx) a casos d'ús científics específics. Cada curs consisteix en una sèrie de mòduls de formació dissenyats per ajudar els estudiants a desenvolupar les seves habilitats progressivament.

:::note[Nextflow per a Genòmica]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Aprèn a desenvolupar un pipeline per a genòmica amb Nextflow.

</div>

Aquest és un curs per a investigadors que volen aprendre a desenvolupar els seus propis pipelines de genòmica. El curs utilitza un cas d'ús de detecció de variants per demostrar com desenvolupar un pipeline de genòmica senzill però funcional.

<LinkButton href="genomics/index.mdx" variant="primary" icon="right-arrow">Comença la formació de Nextflow per a Genòmica</LinkButton>
:::

:::note[Nextflow per a RNAseq]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Aprèn a desenvolupar un pipeline per al processament de dades RNAseq amb Nextflow.

</div>

Aquest és un curs per a investigadors que volen aprendre a desenvolupar els seus propis pipelines de RNAseq. El curs utilitza un cas d'ús de processament de RNAseq massiu per demostrar com desenvolupar un pipeline de RNAseq senzill però funcional.

<LinkButton href="rnaseq/index.mdx" variant="primary" icon="right-arrow">Comença la formació de Nextflow per a RNAseq</LinkButton>
:::

:::note[Nextflow per a Bioimatge]
<div class="starlight-aside starlight-aside--tip inline end">

🏃 Aprèn a executar pipelines per a dades d'imatge amb Nextflow.

Aquest és un curs per a investigadors que volen aprendre a executar i configurar pipelines de bioimatge. El curs utilitza nf-core/molkart per demostrar patrons d'ús essencials de Nextflow aplicables a qualsevol pipeline.

<LinkButton href="imaging/index.mdx" variant="primary" icon="right-arrow">Comença la formació de Nextflow per a Bioimatge</LinkButton>
