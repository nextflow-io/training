## 여러분의 여정

매우 기본적인 워크플로우로 시작하여 실행하고 출력을 찾는 방법을 배웠습니다.
그런 다음 해당 파이프라인의 점점 더 현실적인 버전을 실행했습니다. CSV 파일에서 여러 입력을 병렬로 처리하고, `-resume`을 사용하여 완료된 작업을 건너뛰고, 컨테이너를 사용하여 파이프라인이 의존하는 소프트웨어를 관리하는 방법을 배웠습니다.
다음으로 `nextflow.config`와 프로파일을 사용하여 파이프라인 설정을 맞춤화하는 방법과 출력이 게시되는 위치 및 방식을 제어하는 방법을 배웠습니다.
그 후 실행 보고서를 생성하고, 과거 실행 기록을 확인하고, 오래된 work 디렉토리를 정리하는 방법을 배웠습니다.
마지막으로 GitHub와 같은 원격 저장소에서 직접 파이프라인을 실행하는 방법을 배웠습니다.

### 습득한 기술

이 실습 과정을 통해 다음 방법을 배웠습니다:

- 로컬에서 Nextflow 워크플로우를 실행하고 출력 찾기
- 여러 입력을 병렬로 처리하는 다단계 파이프라인 실행
- `-resume`을 사용하여 완료된 작업 반복 방지
- 컨테이너를 사용하여 소프트웨어 의존성 관리
- `nextflow.config`와 프로파일을 사용하여 파이프라인 설정
- 출력이 게시되는 위치 및 방식 맞춤화
- `-with-report`로 HTML 실행 보고서 생성 및 `-with-timeline`으로 실행 타임라인 생성
- `nextflow log`로 과거 실행 기록 확인
- `nextflow clean`으로 오래된 work 디렉토리 정리
- 원격 저장소에서 직접 파이프라인을 실행하고, 재현성을 위해 특정 리비전에 고정(및 고정 해제)하기

이제 기존 Nextflow 파이프라인을 자신의 작업에 통합하기 위한 기초 지식을 갖추었습니다.
