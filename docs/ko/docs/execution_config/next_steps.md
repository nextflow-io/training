Execution Config 교육 과정을 완료하신 것을 축하합니다! 🎉

## 학습 여정

파이프라인 실행을 다양한 컴퓨팅 환경에 맞게 조정하는 것부터 시작했습니다. 소프트웨어 패키징 기술을 전환하고 실행 플랫폼을 선택하는 방법을 학습했습니다.
다음으로, 리소스 할당을 제어하고 실패한 작업을 자동으로 재시도하는 방법을 학습했습니다.
마지막으로, 설정을 프로파일로 묶고, 런타임에 결합하며, `nextflow config`로 최종 설정을 확인하는 방법을 학습했습니다.

### 습득한 기술

이 실습 과정을 통해 다음을 학습했습니다:

- Docker와 Conda 간 소프트웨어 패키징 기술 전환
- 실행 플랫폼 선택 및 전환 시 내부적으로 변경되는 사항 이해
- 프로세스별 리소스 할당 제어 및 실패한 작업 자동 재시도
- 프로파일 정의 및 결합, `nextflow config`를 통한 설정 확인

이제 다양한 컴퓨팅 환경에 맞게 Nextflow 파이프라인을 자신 있게 설정할 수 있습니다.
