## 학습 여정

Seqera Platform에 가입하고 Community Showcase를 살펴보는 것으로 시작하여, 웹 인터페이스에서 프로덕션 규모의 파이프라인인 `nf-core/rnaseq`를 실행하고 그 실행 과정을 모니터링했습니다.
다음으로, `tw` CLI를 인증하고 터미널에서 모든 작업을 수행하는 방법을 학습했습니다.
마지막으로, GitHub에서 새 파이프라인 `nf-core/demo`를 등록하고 웹 인터페이스와 CLI 모두에서 실행했습니다.

### 학습한 내용

이제 웹 인터페이스와 명령줄 중 어느 것을 선호하든, Seqera Platform에서 Nextflow 파이프라인을 실행하고 모니터링할 수 있습니다.

- 무료 Seqera 계정을 통해 개인 워크스페이스와 Community Showcase에 접근할 수 있습니다.
- 워크스페이스에 추가된 파이프라인은 Launchpad에 표시되며 몇 번의 클릭으로 실행할 수 있습니다.
- `tw` CLI는 웹 인터페이스와 동일한 기능을 제공하며, 스크립팅 및 자동화에 유용합니다.
- `main.nf`와 `nextflow.config`가 있는 GitHub 호스팅 파이프라인은 `tw pipelines add`로 등록할 수 있습니다.
- `tw launch`는 개별 플래그 대신 프로파일과 `--params-file`을 통해 매개변수를 전달합니다.

### 습득한 기술

이 실습 과정을 통해 다음을 수행하는 방법을 학습했습니다:

- Seqera Platform에 가입하고 Community Showcase 살펴보기
- 워크스페이스에 파이프라인을 추가하고 웹 인터페이스에서 실행하기
- 실행 과정을 모니터링하고 작업 수준의 세부 정보 및 보고서 확인하기
- `tw` CLI를 인증하고 터미널에서 파이프라인을 관리 및 실행하기
- GitHub 호스팅 파이프라인을 등록하고 매개변수 파일로 실행하기

이제 Seqera Platform에서 대규모로 자신의 파이프라인을 실행하고 모니터링할 준비가 되었습니다.
