## Sua jornada

Você começou criando uma conta na Seqera Platform e explorando o Community Showcase, depois lançou um pipeline em escala de produção, `nf-core/rnaseq`, pela interface web e monitorou sua execução.
Em seguida, você autenticou o CLI `tw` e aprendeu a fazer tudo pelo terminal.
Por fim, você registrou um novo pipeline, `nf-core/demo`, a partir do GitHub e o lançou tanto pela interface web quanto pelo CLI.

### O que você aprendeu

Agora você é capaz de lançar e monitorar pipelines Nextflow na Seqera Platform, seja pela interface web ou pela linha de comando.

- Uma conta gratuita na Seqera dá acesso a um workspace pessoal e ao Community Showcase.
- Pipelines adicionados a um workspace aparecem no Launchpad e podem ser lançados com poucos cliques.
- O CLI `tw` oferece as mesmas funcionalidades que a interface web, sendo útil para scripts e automação.
- Qualquer pipeline hospedado no GitHub com um `main.nf` e `nextflow.config` pode ser registrado com `tw pipelines add`.
- O `tw launch` recebe parâmetros por meio de profiles e `--params-file`, em vez de flags individuais.

### Habilidades adquiridas

Ao longo deste curso prático, você aprendeu a:

- Criar uma conta na Seqera Platform e explorar o Community Showcase
- Adicionar um pipeline a um workspace e lançar uma execução pela interface web
- Monitorar a execução e inspecionar detalhes e relatórios no nível de tarefa
- Autenticar e usar o CLI `tw` para gerenciar e lançar pipelines pelo terminal
- Registrar um pipeline hospedado no GitHub e lançá-lo com um arquivo de parâmetros

Agora você está pronto para executar e monitorar seus próprios pipelines na Seqera Platform, em escala.
