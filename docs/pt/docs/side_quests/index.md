# Missões Secundárias

<span class="ai-translation-notice">:material-information-outline:{ .ai-translation-notice-icon } Tradução assistida por IA - [saiba mais e sugira melhorias](https://github.com/nextflow-io/training/blob/master/TRANSLATING.md)</span>

**As Missões Secundárias são mini-cursos de treinamento independentes que se aprofundam em tópicos específicos do Nextflow.**

Cada missão secundária pode ser realizada de forma independente, em qualquer ordem, para desenvolver suas habilidades nas áreas que mais importam para seus próprios projetos.
Juntas, elas cobrem as habilidades necessárias para evoluir de pipelines simples para fluxos de trabalho prontos para produção.

<!-- additional_information -->

Se esta é a primeira vez que você realiza um dos nossos treinamentos, comece pela página de [Introdução](./orientation.md) para ter uma visão geral do ambiente de treinamento e dos materiais.
Caso contrário, sinta-se à vontade para mergulhar diretamente na missão que mais chamar sua atenção.
