## Sua jornada

Você começou com um fluxo de trabalho muito básico e aprendeu a executá-lo e encontrar suas saídas.
Em seguida, você executou versões progressivamente mais realistas daquele pipeline: processando múltiplas entradas de um arquivo CSV em paralelo, usando `-resume` para pular trabalhos já concluídos, e usando contêineres para gerenciar o software do qual um pipeline depende.
Depois, você aprendeu como personalizar a configuração de um pipeline usando `nextflow.config` e profiles, e como controlar onde e como suas saídas são publicadas.
Em seguida, você aprendeu como gerar relatórios de execução, inspecionar o histórico de execuções anteriores e limpar diretórios de trabalho antigos.
Por fim, você aprendeu como executar pipelines diretamente de repositórios remotos como o GitHub.

### Habilidades adquiridas

Através deste curso prático, você aprendeu como:

- Iniciar um fluxo de trabalho Nextflow localmente e encontrar suas saídas
- Executar um pipeline de múltiplas etapas que processa várias entradas em paralelo
- Usar `-resume` para evitar repetir trabalhos já concluídos
- Usar contêineres para gerenciar dependências de software
- Configurar pipelines usando `nextflow.config` e profiles
- Personalizar onde e como as saídas são publicadas
- Gerar um relatório de execução em HTML com `-with-report` e uma linha do tempo de execução com `-with-timeline`
- Inspecionar o histórico de execuções anteriores com `nextflow log`
- Limpar diretórios de trabalho antigos com `nextflow clean`
- Executar um pipeline diretamente de um repositório remoto e fixá-lo a uma revisão específica (e desfixá-lo novamente) para reprodutibilidade

Você agora está equipado com o conhecimento fundamental para começar a integrar pipelines Nextflow existentes em seu próprio trabalho.
