## Il vostro percorso

Avete iniziato registrandovi su Seqera Platform ed esplorando il Community Showcase, poi avete lanciato una pipeline di scala produttiva, `nf-core/rnaseq`, dall'interfaccia web e monitorato la sua esecuzione.
Successivamente, avete autenticato il CLI `tw` e imparato a fare tutto dal terminale.
Infine, avete registrato una nuova pipeline, `nf-core/demo`, da GitHub e l'avete lanciata sia dall'interfaccia web che dal CLI.

### Cosa avete imparato

Siete ora in grado di lanciare e monitorare pipeline Nextflow su Seqera Platform, sia che preferiate l'interfaccia web che la riga di comando.

- Un account Seqera gratuito vi offre uno spazio di lavoro personale e l'accesso al Community Showcase.
- Le pipeline aggiunte a uno spazio di lavoro appaiono nel Launchpad e possono essere lanciate con pochi clic.
- Il CLI `tw` offre le stesse funzionalità dell'interfaccia web, utile per la creazione di script e l'automazione.
- Qualsiasi pipeline ospitata su GitHub con un `main.nf` e un `nextflow.config` può essere registrata con `tw pipelines add`.
- `tw launch` accetta i parametri tramite profili e `--params-file`, anziché tramite flag individuali.

### Competenze acquisite

Attraverso questo corso pratico, avete imparato a:

- Registrarsi su Seqera Platform ed esplorare il Community Showcase
- Aggiungere una pipeline a uno spazio di lavoro e lanciare un'esecuzione dall'interfaccia web
- Monitorare l'esecuzione e ispezionare i dettagli e i report a livello di attività
- Autenticare e utilizzare il CLI `tw` per gestire e lanciare pipeline dal terminale
- Registrare una pipeline ospitata su GitHub e lanciarla con un file di parametri

Siete ora pronti per eseguire e monitorare le vostre pipeline su Seqera Platform, su larga scala.
