## Tu recorrido

Comenzaste adaptando la ejecución de un pipeline a diferentes entornos de cómputo: cambiando la tecnología de empaquetado de software y seleccionando una plataforma de ejecución.
Luego, aprendiste a controlar la asignación de recursos y a reintentar automáticamente las tareas que fallan.
Finalmente, aprendiste a agrupar la configuración en perfiles, combinarlos en tiempo de ejecución e inspeccionar la configuración completamente resuelta.

### Habilidades adquiridas

A través de este curso práctico, aprendiste a:

- Cambiar la tecnología de empaquetado de software entre Docker y Conda
- Seleccionar una plataforma de ejecución y comprender qué cambia internamente cuando lo haces
- Controlar la asignación de recursos por proceso y reintentar automáticamente las tareas que fallan
- Definir y combinar perfiles, e inspeccionar la configuración resuelta con `nextflow config`

Ahora estás preparado/a para configurar pipelines de Nextflow en una variedad de entornos de cómputo con confianza.
