## Tu recorrido

Comenzaste registrándote en Seqera Platform y explorando el Community Showcase, luego lanzaste un pipeline de escala productiva, `nf-core/rnaseq`, desde la interfaz web y monitoreaste su ejecución.
A continuación, autenticaste el CLI `tw` y aprendiste a hacer todo desde la terminal.
Finalmente, registraste un nuevo pipeline, `nf-core/demo`, desde GitHub y lo lanzaste tanto desde la interfaz web como desde el CLI.

### Lo que aprendiste

Ahora eres capaz de lanzar y monitorear pipelines de Nextflow en Seqera Platform, ya sea que prefieras la interfaz web o la línea de comandos.

- Una cuenta gratuita de Seqera te da un espacio de trabajo personal y acceso al Community Showcase.
- Los pipelines agregados a un espacio de trabajo aparecen en el Launchpad y pueden lanzarse con unos pocos clics.
- El CLI `tw` ofrece las mismas capacidades que la interfaz web, lo que resulta útil para scripting y automatización.
- Cualquier pipeline alojado en GitHub con un `main.nf` y `nextflow.config` puede registrarse con `tw pipelines add`.
- `tw launch` recibe parámetros a través de perfiles y `--params-file`, en lugar de indicadores individuales.

### Habilidades adquiridas

A través de este curso práctico, aprendiste a:

- Registrarte en Seqera Platform y explorar el Community Showcase
- Agregar un pipeline a un espacio de trabajo y lanzar una ejecución desde la interfaz web
- Monitorear la ejecución e inspeccionar los detalles y reportes a nivel de tarea
- Autenticar y usar el CLI `tw` para gestionar y lanzar pipelines desde la terminal
- Registrar un pipeline alojado en GitHub y lanzarlo con un archivo de parámetros

Ahora estás preparado/a para ejecutar y monitorear tus propios pipelines en Seqera Platform, a escala.
