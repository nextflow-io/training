## Deine Reise

Du hast dich bei Seqera Platform angemeldet und die Community Showcase erkundet, dann eine produktionsreife Pipeline, `nf-core/rnaseq`, über die Weboberfläche gestartet und ihre Ausführung überwacht.
Anschließend hast du die `tw` CLI authentifiziert und gelernt, alles vom Terminal aus zu erledigen.
Zum Schluss hast du eine neue Pipeline, `nf-core/demo`, von GitHub registriert und sie sowohl über die Weboberfläche als auch über die CLI gestartet.

### Was du gelernt hast

Du kannst jetzt Nextflow-Pipelines auf Seqera Platform starten und überwachen – egal ob du die Weboberfläche oder die Kommandozeile bevorzugst.

- Ein kostenloses Seqera-Konto gibt dir einen persönlichen Workspace und Zugang zur Community Showcase.
- Pipelines, die einem Workspace hinzugefügt wurden, erscheinen im Launchpad und können mit wenigen Klicks gestartet werden.
- Die `tw` CLI bietet dieselben Funktionen wie die Weboberfläche und ist nützlich für Scripting und Automatisierung.
- Jede auf GitHub gehostete Pipeline mit einer `main.nf` und `nextflow.config` kann mit `tw pipelines add` registriert werden.
- `tw launch` nimmt Parameter über Profile und `--params-file` entgegen, nicht über einzelne Flags.

### Erworbene Fähigkeiten

In diesem praxisorientierten Kurs hast du gelernt, wie du:

- dich bei Seqera Platform anmeldest und die Community Showcase erkundest
- eine Pipeline zu einem Workspace hinzufügst und einen Run über die Weboberfläche startest
- die Ausführung überwachst und Details sowie Berichte auf Aufgabenebene einsehen kannst
- die `tw` CLI authentifizierst und verwendest, um Pipelines vom Terminal aus zu verwalten und zu starten
- eine auf GitHub gehostete Pipeline registrierst und mit einer Parameterdatei startest

Du bist jetzt bereit, deine eigenen Pipelines auf Seqera Platform in großem Maßstab auszuführen und zu überwachen.
