## एक प्रशिक्षण वातावरण शुरू करो

GitHub Codespaces पर हमारे द्वारा प्रदान किए गए pre-built वातावरण का उपयोग करने के लिए, नीचे दिए गए "Open in GitHub Codespaces" बटन पर क्लिक करो। अन्य विकल्पों के लिए, [पर्यावरण विकल्प](../envsetup/index.md) देखो।

हम सुझाव देते हैं कि प्रशिक्षण वातावरण को एक नए browser tab या window में खोलो (अपने उपकरण के अनुसार right-click, ctrl-click या cmd-click का उपयोग करो) ताकि वातावरण लोड होते समय तुम पढ़ते रह सको।
कोर्स के दौरान काम करने के लिए तुम्हें ये निर्देश साथ-साथ खुले रखने होंगे।

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/nextflow-io/training?quickstart=1&ref=master)

### वातावरण की मूल बातें

इस प्रशिक्षण वातावरण में प्रशिक्षण कोर्स के लिए आवश्यक सभी सॉफ़्टवेयर, कोड और डेटा मौजूद हैं, इसलिए तुम्हें खुद कुछ भी इंस्टॉल करने की ज़रूरत नहीं है।

codespace एक VSCode इंटरफ़ेस के साथ सेट किया गया है, जिसमें एक filesystem explorer, एक code editor और एक terminal shell शामिल है।
कोर्स के दौरान दिए गए सभी निर्देश (जैसे 'फ़ाइल खोलो', 'कोड संपादित करो' या 'यह कमांड चलाओ') जब तक अन्यथा न कहा जाए, VSCode इंटरफ़ेस के इन्हीं तीन हिस्सों को संदर्भित करते हैं।

अगर तुम यह कोर्स अकेले कर रहे हो, तो अधिक जानकारी के लिए कृपया [वातावरण की मूल बातें](../envsetup/01_setup.md) से परिचित हो जाओ।

## काम के लिए तैयार हो जाओ

एक बार तुम्हारा codespace चल जाए, तो शुरू करने से पहले दो काम करने हैं: अपनी working directory सेट करो, और प्रदान की गई सामग्री पर एक नज़र डालो।

### Working directory सेट करो

डिफ़ॉल्ट रूप से, codespace सभी प्रशिक्षण कोर्सों के root पर खुलता है।
इस कोर्स के लिए, `seqera-scale/` डायरेक्टरी में जाओ:

```bash
cd seqera-scale/
```

फिर VSCode को इस डायरेक्टरी पर focus करने के लिए सेट करो, ताकि file explorer sidebar में केवल संबंधित फ़ाइलें दिखें:

```bash
code .
```

!!! tip "सुझाव"

    अगर किसी कारण से तुम इस डायरेक्टरी से बाहर चले जाओ (जैसे तुम्हारा codespace सो जाए), तो तुम हमेशा पूरे path का उपयोग करके वापस आ सकते हो, यह मानते हुए कि तुम Github Codespaces प्रशिक्षण वातावरण के अंदर चला रहे हो:

    ```bash
    cd /workspaces/training/seqera-scale
    ```

### प्रदान की गई सामग्री देखो

तुम बाईं ओर file explorer का उपयोग करके, या `tree` कमांड से कोर्स सामग्री देख सकते हो।
पूरी संरचना देखने के लिए terminal से निम्नलिखित चलाओ:

```bash
tree -a .
```

??? abstract "डायरेक्टरी सामग्री"

    ```console
    .
    └── .seqera_config
    ```

**`.seqera_config`** फ़ाइल एक stub है जिसे तुम section 3 के दौरान `tw` CLI को अपने Seqera access token और workspace के साथ configure करने के लिए भरोगे।
