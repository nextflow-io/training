## तुम्हारी यात्रा

तुमने Seqera Platform के लिए साइन अप करके और Community Showcase को एक्सप्लोर करके शुरुआत की, फिर वेब इंटरफ़ेस से एक प्रोडक्शन-स्केल पाइपलाइन, `nf-core/rnaseq`, लॉन्च की और उसके execution को मॉनिटर किया।
इसके बाद, तुमने `tw` CLI को authenticate किया और टर्मिनल से ही सब कुछ करना सीखा।
अंत में, तुमने GitHub से एक नई पाइपलाइन, `nf-core/demo`, रजिस्टर की और उसे वेब इंटरफ़ेस और CLI दोनों से लॉन्च किया।

### तुमने क्या सीखा

अब तुम Seqera Platform पर Nextflow पाइपलाइन लॉन्च और मॉनिटर करने में सक्षम हो, चाहे तुम वेब इंटरफ़ेस पसंद करो या कमांड लाइन।

- एक मुफ़्त Seqera अकाउंट तुम्हें एक पर्सनल workspace और Community Showcase तक पहुँच देता है।
- किसी workspace में जोड़ी गई पाइपलाइनें Launchpad में दिखती हैं और कुछ क्लिक में लॉन्च की जा सकती हैं।
- `tw` CLI वेब इंटरफ़ेस जैसी ही क्षमताएँ प्रदान करता है, जो scripting और automation के लिए उपयोगी है।
- GitHub पर होस्ट की गई कोई भी पाइपलाइन जिसमें `main.nf` और `nextflow.config` हो, उसे `tw pipelines add` से रजिस्टर किया जा सकता है।
- `tw launch` पैरामीटर profiles और `--params-file` के ज़रिए लेता है, न कि अलग-अलग flags से।

### अर्जित कौशल

इस व्यावहारिक कोर्स के ज़रिए, तुमने सीखा कि कैसे:

- Seqera Platform के लिए साइन अप करें और Community Showcase एक्सप्लोर करें
- किसी workspace में पाइपलाइन जोड़ें और वेब इंटरफ़ेस से एक run लॉन्च करें
- Execution मॉनिटर करें और कार्य-स्तरीय विवरण और रिपोर्ट देखें
- `tw` CLI को authenticate करें और टर्मिनल से पाइपलाइन मैनेज और लॉन्च करें
- GitHub पर होस्ट की गई पाइपलाइन रजिस्टर करें और उसे पैरामीटर फ़ाइल के साथ लॉन्च करें

अब तुम Seqera Platform पर, बड़े पैमाने पर, अपनी खुद की पाइपलाइन चलाने और मॉनिटर करने के लिए तैयार हो।
