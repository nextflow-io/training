## एक प्रशिक्षण वातावरण शुरू करो

GitHub Codespaces पर हमारे द्वारा प्रदान किए गए pre-built वातावरण का उपयोग करने के लिए, नीचे दिए गए "Open in GitHub Codespaces" बटन पर क्लिक करो। अन्य विकल्पों के लिए, [वातावरण के विकल्प](../envsetup/index.md) देखो।

हम अनुशंसा करते हैं कि प्रशिक्षण वातावरण को एक नए ब्राउज़र टैब या विंडो में खोलो (अपने उपकरण के अनुसार right-click, ctrl-click या cmd-click का उपयोग करो) ताकि वातावरण लोड होते समय तुम पढ़ते रह सको।
कोर्स के दौरान काम करने के लिए तुम्हें इन निर्देशों को साथ-साथ खुला रखना होगा।

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/nextflow-io/training?quickstart=1&ref=master)

### वातावरण की मूल बातें

इस प्रशिक्षण वातावरण में प्रशिक्षण कोर्स को पूरा करने के लिए आवश्यक सभी सॉफ़्टवेयर, कोड और डेटा मौजूद हैं, इसलिए तुम्हें खुद कुछ भी इंस्टॉल करने की ज़रूरत नहीं है।

codespace एक VSCode इंटरफ़ेस के साथ सेट किया गया है, जिसमें एक filesystem explorer, एक code editor और एक terminal shell शामिल है।
कोर्स के दौरान दिए गए सभी निर्देश (जैसे 'फ़ाइल खोलो', 'कोड संपादित करो' या 'यह कमांड चलाओ') उन तीन हिस्सों को संदर्भित करते हैं जब तक अन्यथा न कहा जाए।

अगर तुम यह कोर्स अकेले कर रहे हो, तो अधिक जानकारी के लिए कृपया [वातावरण की मूल बातें](../envsetup/01_setup.md) से परिचित हो जाओ।

### संस्करण आवश्यकताएँ

इस कोर्स के लिए Nextflow 25.10.2 या उसके बाद का संस्करण आवश्यक है, जिसमें v2 syntax parser सक्षम हो (25.10+ में यह डिफ़ॉल्ट है)।
अगर तुम कोई लोकल या कस्टम वातावरण उपयोग कर रहे हो, तो कृपया सुनिश्चित करो कि तुम [यहाँ](../info/nxf_versions.md) दर्ज सही सेटिंग्स का उपयोग कर रहे हो।

## काम के लिए तैयार हो जाओ

एक बार तुम्हारा codespace चल जाए, तो शुरू करने से पहले दो काम करने हैं: अपनी working directory सेट करो, और प्रदान की गई सामग्री पर एक नज़र डालो।

### Working directory सेट करो

डिफ़ॉल्ट रूप से, codespace सभी प्रशिक्षण कोर्सों की root पर खुलता है।
इस कोर्स के लिए, `config-exec/` डायरेक्टरी में जाओ:

```bash
cd config-exec/
```

फिर VSCode को इस डायरेक्टरी पर फ़ोकस करने के लिए सेट करो, ताकि file explorer sidebar में केवल संबंधित फ़ाइलें दिखें:

```bash
code .
```

!!! tip "सुझाव"

    अगर किसी कारण से तुम इस डायरेक्टरी से बाहर चले जाओ (जैसे तुम्हारा codespace सो जाए), तो तुम हमेशा पूरे path का उपयोग करके वापस आ सकते हो, यह मानते हुए कि तुम Github Codespaces प्रशिक्षण वातावरण में चला रहे हो:

    ```bash
    cd /workspaces/training/config-exec
    ```

### प्रदान की गई सामग्री को एक्सप्लोर करो

तुम बाईं ओर file explorer का उपयोग करके, या `tree` कमांड से कोर्स सामग्री को एक्सप्लोर कर सकते हो।
पूरी संरचना देखने के लिए terminal से निम्नलिखित चलाओ:

```bash
tree . -L 2
```

??? abstract "डायरेक्टरी सामग्री"

    ```console
    .
    ├── data
    │   └── greetings.csv
    ├── main.nf
    ├── modules
    │   ├── collectGreetings.nf
    │   ├── convertToUpper.nf
    │   ├── cowpy.nf
    │   └── sayHello.nf
    └── nextflow.config
    ```

**`main.nf`** और **`modules/`** फ़ाइलें [Nextflow Run](../nextflow_run/index.md) से वही multi-step पाइपलाइन हैं, और **`nextflow.config`** फ़ाइल वही कॉन्फ़िगरेशन है जो तुमने वहाँ पहले देखी थी।
इन अभ्यासों के दौरान तुम दोनों को विस्तारित करोगे।

**`data/`** डायरेक्टरी में वह CSV इनपुट फ़ाइल है जिसे पाइपलाइन पढ़ती है।

- [ ] मेरा वातावरण चल रहा है
