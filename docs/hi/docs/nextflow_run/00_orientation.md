## एक प्रशिक्षण वातावरण शुरू करें

GitHub Codespaces पर हमारे द्वारा प्रदान किए गए पूर्व-निर्मित वातावरण का उपयोग करने के लिए, नीचे "Open in GitHub Codespaces" बटन पर क्लिक करो। अन्य विकल्पों के लिए, [वातावरण विकल्प](../envsetup/index.md) देखो।

हम अनुशंसा करते हैं कि प्रशिक्षण वातावरण को एक नए ब्राउज़र टैब या विंडो में खोलो (अपने उपकरण के आधार पर राइट-क्लिक, ctrl-क्लिक या cmd-क्लिक का उपयोग करो) ताकि वातावरण लोड होने के दौरान तुम पढ़ते रह सको।
कोर्स के माध्यम से काम करने के लिए तुम्हें इन निर्देशों को समानांतर में खुला रखना होगा।

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/nextflow-io/training?quickstart=1&ref=master)

### वातावरण की मूल बातें

इस प्रशिक्षण वातावरण में प्रशिक्षण कोर्स के माध्यम से काम करने के लिए आवश्यक सभी software, कोड और डेटा शामिल है, इसलिए तुम्हें स्वयं कुछ भी इंस्टॉल करने की आवश्यकता नहीं है।

Codespace एक VSCode इंटरफ़ेस के साथ सेट अप है, जिसमें एक filesystem explorer, एक code editor और एक terminal shell शामिल है।
कोर्स के दौरान दिए गए सभी निर्देश (जैसे 'फ़ाइल खोलो', 'कोड एडिट करो' या 'यह कमांड चलाओ') अन्यथा निर्दिष्ट न होने पर VSCode इंटरफ़ेस के उन तीन भागों को संदर्भित करते हैं।

यदि तुम इस कोर्स को स्वयं कर रहे हो, तो कृपया अधिक विवरण के लिए [वातावरण की मूल बातें](../envsetup/01_setup.md) से परिचित हो जाओ।

### संस्करण आवश्यकताएं

इस कोर्स के लिए Nextflow 25.10.2 या बाद के संस्करण की आवश्यकता है, जिसमें v2 syntax parser सक्षम हो (25.10+ में यह डिफ़ॉल्ट है)।
यदि तुम एक स्थानीय या कस्टम वातावरण का उपयोग कर रहे हो, तो कृपया सुनिश्चित करो कि तुम [यहां](../info/nxf_versions.md) documented सही सेटिंग्स का उपयोग कर रहे हो।

## काम करने के लिए तैयार हो जाओ

एक बार तुम्हारा codespace चल रहा हो, तो प्रशिक्षण में गोता लगाने से पहले तुम्हें दो काम करने होंगे: अपनी working directory सेट करो, और प्रदान की गई सामग्री पर एक नज़र डालो।

### Working directory सेट करो

डिफ़ॉल्ट रूप से, codespace सभी प्रशिक्षण कोर्सों की root पर खुलता है।
इस कोर्स के लिए, `nextflow-run/` डायरेक्टरी में जाओ:

```bash
cd nextflow-run/
```

फिर VSCode को इस डायरेक्टरी पर फोकस करने के लिए सेट करो, ताकि file explorer sidebar में केवल प्रासंगिक फ़ाइलें दिखें:

```bash
code .
```

!!! tip "सुझाव"

    यदि किसी भी कारण से तुम इस डायरेक्टरी से बाहर निकल जाते हो (जैसे तुम्हारा codespace स्लीप हो जाता है), तो तुम हमेशा इसमें वापस आने के लिए पूर्ण पथ का उपयोग कर सकते हो, यह मानते हुए कि तुम इसे Github Codespaces प्रशिक्षण वातावरण के भीतर चला रहे हो:

    ```bash
    cd /workspaces/training/nextflow-run
    ```

### प्रदान की गई सामग्री का अन्वेषण करो

तुम बाईं ओर file explorer का उपयोग करके कोर्स सामग्री का अन्वेषण कर सकते हो, या `tree` कमांड के साथ।
पूरी संरचना देखने के लिए terminal से यह चलाओ:

```bash
tree . -L 2
```

??? abstract "डायरेक्टरी सामग्री"

    ```console
    .
    ├── 1-hello.nf
    ├── 2-inputs.nf
    ├── data
    │   ├── greetings-extended.csv
    │   └── greetings.csv
    ├── main.nf
    ├── modules
    │   ├── collectGreetings.nf
    │   ├── convertToUpper.nf
    │   ├── cowpy.nf
    │   └── sayHello.nf
    └── nextflow.config
    ```

**`.nf` फ़ाइलें** बढ़ती जटिलता के workflow scripts हैं, जिनका उपयोग कोर्स में उसी क्रम में किया जाता है।

**`data/`** डायरेक्टरी में CSV इनपुट फ़ाइलें हैं जिनका उपयोग हम सेक्शन 2 से शुरू करके करेंगे।

**`modules/`** डायरेक्टरी में `main.nf` द्वारा उपयोग की जाने वाली प्रोसेस definitions हैं।

**`nextflow.config`** फ़ाइल एक configuration फ़ाइल है जो न्यूनतम वातावरण गुण सेट करती है। तुम अभी के लिए इसे अनदेखा कर सकते हो; हम इसे सेक्शन 4 में देखेंगे।
