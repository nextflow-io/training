## तुम्हारी यात्रा

तुमने `nf-core/demo` पाइपलाइन खोजने और प्राप्त करने से शुरुआत की, फिर इसे test profile का उपयोग करके चलाना और इसके आउटपुट की जांच करना सीखा।
इसके बाद, तुमने पाइपलाइन पैरामीटर और कॉन्फ़िगरेशन फ़ाइलों के माध्यम से इसके निष्पादन को कॉन्फ़िगर किया, और देखा कि nf-core पाइपलाइन पैरामीटर और इनपुट डेटा को कैसे validate करती हैं।
अंत में, तुमने उन्हीं कौशलों को `nf-core/rnaseq` पर लागू किया, जो एक production-scale पाइपलाइन है, और सीखा कि अपने उपलब्ध हार्डवेयर के अनुसार इसके डिफ़ॉल्ट resource allocations को कैसे override करें।

### तुमने क्या सीखा

अब तुम nf-core पाइपलाइन खोज, प्राप्त, चला और कॉन्फ़िगर कर सकते हो।

- nf-core पाइपलाइन `nextflow pull` से प्राप्त की जाती हैं और एक मानक कोड संगठन का पालन करती हैं।
- हर nf-core पाइपलाइन एक छोटे डेटासेट पर त्वरित validation के लिए `test` profile के साथ आती है।
- पाइपलाइन पैरामीटर (`--param_name` या `-params-file` के ज़रिए सेट) और कॉन्फ़िगरेशन (`-c` के ज़रिए सेट) अलग-अलग उद्देश्यों की पूर्ति करते हैं: इनपुट और विश्लेषण विकल्प बनाम resource allocation जैसी निष्पादन संबंधी व्यवस्था।
- nf-core पाइपलाइन पैरामीटर और इनपुट फ़ाइलों को स्वचालित रूप से validate करती हैं, जिससे कोई भी कार्य शुरू होने से पहले त्रुटियाँ पकड़ी जाती हैं।
- Resource defaults को labels (`process_low`, `process_medium`, `process_high`) के माध्यम से असाइन किया जाता है जो `conf/base.config` में परिभाषित होते हैं, जिन्हें तुम एक कस्टम कॉन्फ़िगरेशन फ़ाइल से override कर सकते हो।

### अर्जित कौशल

इस व्यावहारिक कोर्स के माध्यम से, तुमने सीखा कि कैसे:

- nf-co.re वेबसाइट पर nf-core पाइपलाइन खोजें और उसका सोर्स कोड प्राप्त करें
- पाइपलाइन के बिल्ट-इन test profile का उपयोग करके उसे चलाएं और उसके आउटपुट की जांच करें
- सहायता प्राप्त करें, पैरामीटर सेट करें, और पैरामीटर व इनपुट validation को समझें
- कॉन्फ़िगरेशन फ़ाइलों के माध्यम से resource allocation और टूल arguments को कस्टमाइज़ करें
- एक production-scale पाइपलाइन pull और चलाएं, और उसके डिफ़ॉल्ट resource labels को override करें

अब तुम अपने स्वयं के विश्लेषणों के लिए nf-core पाइपलाइन चलाना शुरू करने के लिए आवश्यक बुनियादी ज्ञान से लैस हो।
