Felicitats per completar el curs de formació Execution Config! 🎉

## El vostre recorregut

Heu començat adaptant l'execució d'un pipeline a diferents entorns de càlcul: canviant la tecnologia d'empaquetament de programari i seleccionant una plataforma d'execució.
A continuació, heu après a controlar les assignacions de recursos i a reintentar automàticament les tasques que fallen.
Finalment, heu après a agrupar la configuració en perfils, combinar-los en temps d'execució i inspeccionar la configuració completament resolta.

### Habilitats adquirides

A través d'aquest curs pràctic, heu après a:

- Canviar la tecnologia d'empaquetament de programari entre Docker i Conda
- Seleccionar una plataforma d'execució i entendre què canvia internament quan ho feu
- Controlar les assignacions de recursos per procés i reintentar automàticament les tasques que fallen
- Definir i combinar perfils, i inspeccionar la configuració resolta amb `nextflow config`

Ara esteu preparats per configurar pipelines de Nextflow per a una varietat d'entorns de càlcul amb confiança.
