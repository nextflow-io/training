## Votre parcours

Vous avez commencé par vous inscrire sur Seqera Platform et explorer la Community Showcase, puis vous avez lancé un pipeline à l'échelle de la production, `nf-core/rnaseq`, depuis l'interface web et surveillé son exécution.
Ensuite, vous avez authentifié le CLI `tw` et appris à tout faire depuis le terminal.
Enfin, vous avez enregistré un nouveau pipeline, `nf-core/demo`, depuis GitHub et l'avez lancé à la fois depuis l'interface web et le CLI.

### Ce que vous avez appris

Vous êtes maintenant en mesure de lancer et de surveiller des pipelines Nextflow sur Seqera Platform, que vous préfériez l'interface web ou la ligne de commande.

- Un compte Seqera gratuit vous donne accès à un espace de travail personnel et à la Community Showcase.
- Les pipelines ajoutés à un espace de travail apparaissent dans le Launchpad et peuvent être lancés en quelques clics.
- Le CLI `tw` offre les mêmes fonctionnalités que l'interface web, ce qui est utile pour les scripts et l'automatisation.
- Tout pipeline hébergé sur GitHub avec un fichier `main.nf` et un fichier `nextflow.config` peut être enregistré avec `tw pipelines add`.
- `tw launch` prend en charge les paramètres via des profils et `--params-file`, plutôt que des options individuelles.

### Compétences acquises

Au cours de cette formation pratique, vous avez appris à :

- Vous inscrire sur Seqera Platform et explorer la Community Showcase
- Ajouter un pipeline à un espace de travail et lancer une exécution depuis l'interface web
- Surveiller l'exécution et inspecter les détails et les rapports au niveau des tâches
- Authentifier et utiliser le CLI `tw` pour gérer et lancer des pipelines depuis le terminal
- Enregistrer un pipeline hébergé sur GitHub et le lancer avec un fichier de paramètres

Vous êtes désormais équipé·e pour exécuter et surveiller vos propres pipelines sur Seqera Platform, à grande échelle.
